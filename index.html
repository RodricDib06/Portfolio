        02

        Limit Order Book & Real-Time Risk Engine

        The core of a stock exchange in C++17, with a risk layer that can stop a losing trader in O(log n).

        • RoleSolo build
        • Year2026
        • Status116 tests, CI green
        • Price-time priority matching with 7 pre-trade risk checks, live P&L for every account, and a loss-limit kill switch.
        • Removed hot-path allocations with a pooled intrusive list: 9.4M → 20M orders/sec (+112%), 50 ns per order.
        • Loss limits become trigger prices in two ordered maps, so a price move only visits the accounts it breaches instead of scanning all of them.
        • 116 tests on GCC and Clang with AddressSanitizer + UBSan in CI. Invariants are re-checked after every single operation.

        The 7 pre-trade checks

        1. Max order quantity
        2. Max order value
        3. Price band
        4. Position limit
        5. Credit limit
        6. Self-trade prevention
        7. Kill switch
        • C++17
        • CMake
        • GoogleTest
        • GitHub Actions
        • ASan / UBSan
        • Linux
